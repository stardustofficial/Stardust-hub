# ✨ STARDUST HUB ✨

### *Where Connections Shine Like Stars*

---

## 📱 **About Stardust Hub**

**Stardust Hub** is a modern, feature-rich social media platform built with cutting-edge web technologies. It provides a seamless experience for connecting, sharing, and communicating with friends and family in a secure environment.

---

## 🚀 **Key Features**

### 👤 **User Management**
- Full profile creation with PFP, Name, Bio, Email
- Secure Firebase Authentication
- Forgot Password with email reset link
- Delete Account option with confirmation
- Dark/Light Mode toggle
- Premium Features with themes, frames, and fonts

### 📝 **Posts**
- Create posts with text & images
- 3-Dot Menu for Edit & Delete (owner only)
- Like system with real-time updates
- Comment system with delete option
- Save posts to personal collection
- Share posts with friends

### 🎬 **Reels**
- Upload short videos with captions
- 3-Dot Menu for Edit & Delete (owner only)
- Like system with real-time updates
- Comment system
- View counter (one view per user)
- Save reels to personal collection
- Share reels with friends

### 💬 **Chat System**
- Real-time messaging
- Seen status for messages
- Share posts & reels directly in chat
- Reactions with emojis
- Voice calls via PeerJS
- Minimizable call window with drag support

### 🤝 **Social Features**
- Friend request system
- Accept/Deny friend requests
- Search users by name or UID
- Search posts by content
- Notifications for likes, comments, friend requests

### 🎨 **Premium Features**
- 10 Premium Themes (Galaxy, Sunset, Ocean, Forest, Rose, Gold, Ice, Almond, Royal, Cherry)
- 9 Premium Frames (Glow, Rainbow, Gold, Cyan, Pink, Purple, Emerald, Almond, Royal)
- 9 Premium Fonts (Elegant, Modern, Bold, Cursive, Mono, Neon, Soft, Luxury, Futuristic)
- Glowing Profile with premium badge

---

## 🛠️ **Tech Stack**

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure |
| Tailwind CSS | Styling & Responsive Design |
| JavaScript (ES6+) | Interactivity & Logic |
| Firebase Auth | User Authentication |
| Firebase Realtime DB | Database & Real-time updates |
| PeerJS | Voice Calls (P2P) |
| Cloudinary | Video & Image Uploads |

---

## 📦 **Installation**

### Prerequisites
- A modern web browser
- Firebase account with Auth & Realtime Database
- Cloudinary account for media uploads
